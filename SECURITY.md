# Security policy

## Reporting a vulnerability

Please report security issues through **GitHub Security Advisories**
("Security" tab → "Report a vulnerability") on this repository. That gives us a
private thread and a coordinated disclosure path.

Please do not open a public issue for a vulnerability.

Include, when you can: affected version (the release tag), the device/Android
version, reproduction steps, and any logs or stack traces with secrets removed.

## Scope

This is a personal, hobby project published for its owner's own devices. Signed
APKs are built from tagged commits; anything you did not download from this
repository's Releases page is not ours.

## What is in scope

- The app itself and its release artefacts
- The CI workflows in `.github/workflows/`

## What is out of scope

- Bugs in the upstream projects this app depends on (report those upstream)
- Anything requiring a rooted device or physical access
- Denial of service from your own network or server configuration

## Our side of the deal

We will acknowledge a report as soon as we reasonably can, keep you updated on
the fix, and credit you in the release notes unless you ask otherwise.
